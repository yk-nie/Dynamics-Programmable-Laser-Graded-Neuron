This folder contains the following code files for the **Panama electricity prediction task**:

- Panama_static_sigmoid.ipynb: static sigmoid model.
- Panama_different_nonlinearity.ipynb: static nonlinear model with different nonlinear functions.
- Panama_tunable_sigmoid.ipynb: static sigmoid model when tuning the shape of the sigmoid function.
- Panama_MLP.ipynb: MLP model.
- continuous dataset.csv: original dataset.

The '.txt' files are the simulation results of the MLP model.
