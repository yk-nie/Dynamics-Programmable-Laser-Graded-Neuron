This folder contains the following code files for the Mackey-Glass task:

- Mackey_Glass_static_tanh.ipynb: static tanh model.
- Mackey_Glass_different_nonlinearity.ipynb: static nonlinear model with different nonlinear functions.
- Mackey_Glass_tunable_tanh.ipynb: static tanh model when tuning the shape of the tanh functions.
- Mackey_Glass_MLP.ipynb: MLP model.

The .txt files are the simulation results of the MLP model.
